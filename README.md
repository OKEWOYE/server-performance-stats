# Server Performance Stats

A Bash script for monitoring Linux server performance.

## Features
- CPU usage
- Memory usage
- Disk usage
- Top 5 CPU processes
- Top 5 memory processes
- Operating system information
- System uptime
- Load average

## How to Run

Make the script executable:

    chmod +x server-stats.sh

Run the script:

    ./server-stats.sh

## Tools
Bash, Linux, awk, Git

## Environment
Ubuntu 24.04.3 LTS on WSL2.
